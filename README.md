# Solar Park Forecast Console

Static website for a B.Tech research project (NIT Patna, Department of Electrical Engineering): short-term solar power
forecasts for India's MNRE-sanctioned solar parks. Test period January to September 2026.

* 'Actual' output is simulated with pvlib from ERA5 weather; no park publishes hourly metered output.
* Model inputs are ECMWF forecasts issued one or two days earlier (Open-Meteo).
* Boundaries: datameet (Survey-of-India-based). Park positions approximate (OpenStreetMap).
